# 抖音内容下载器（Chrome 扩展）

在抖音网页版（douyin.com）打开任意视频 / 图文 / 动图后，点一下工具栏上的扩展图标，
内容会自动下载到「下载」目录下的 `抖音下载/` 文件夹里，按内容标题建子文件夹。

## 安装步骤（只需一次）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角的 **开发者模式** 开关
3. 点击左上角 **加载已解压的扩展程序**
4. 选择本文件夹（`抖音下载器`）→ 完成
5. 建议点击工具栏拼图图标 🧩，把「抖音内容下载器」固定 📌 到工具栏

## 使用方法

1. 在 douyin.com 上点开想下载的视频或图文（弹出播放窗口即可）
2. 点击工具栏上的扩展图标
3. 图标上出现绿色数字 = 已开始下载对应数量的文件
4. 文件保存在 Chrome 默认下载目录的 `抖音下载/内容标题/` 里：
   - 普通视频 → `视频.mp4`
   - 图文帖 → `图1.jpg`、`图2.jpg` …
   - 图文里的动图（实况） → `图N_动图.mp4`（抖音的动图本质是循环短视频）

## 工作原理（供学习）

1. 从当前页面网址中提取内容 ID（`modal_id=` 或 `/video/` 后面的数字）
2. 在页面内调用抖音自己的详情接口 `/aweme/v1/web/aweme/detail/`（自动带上登录 Cookie）
3. 从返回的 JSON 中提取 `video.play_addr`（视频）和 `images[i].url_list` / `images[i].video.play_addr`（静图 / 动图）的原始地址
4. 通过 `chrome.downloads` API 下载；并用 declarativeNetRequest 规则给发往
   `douyinvod.com` / `douyinpic.com` 的请求自动补 `Referer: https://www.douyin.com/`，避免 403

## 注意事项

- 媒体链接带签名和有效期（几小时后失效），扩展每次都是现取现下，不受影响；
  但手动复制的旧链接不能反复使用
- 数据来自你自己浏览器中已登录/已打开的页面，仅用于保存你喜欢的内容，请尊重创作者版权，勿用于商业用途
- 如果接口临时限流导致提取失败，等几秒再点一次即可

## 文件说明

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展配置（MV3），声明权限和 CDN 域名 |
| `background.js` | 核心逻辑：提取内容 ID → 调接口 → 解析地址 → 触发下载 |
| `rules.json` | 网络规则：给 CDN 请求补 Referer，绕过 403 |
| `icon128.png` | 图标 |
